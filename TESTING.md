# Инструкции по тестированию Telegram Dating Bot

## Подготовка к тестированию

### 1. Установка зависимостей

Откройте PowerShell в папке проекта:

```powershell
cd C:\Users\ruslan\PycharmProjects\tg_bot
.\new-env\Scripts\pip.exe install -r req.txt
.\new-env\Scripts\pip.exe install python-dotenv
```

### 2. Создание .env файла

Если файл .env не существует, скопируйте .env.example:

```powershell
copy .env.example .env
```

Отредактируйте .env и добавьте ваш BOT_TOKEN:
```
BOT_TOKEN=ваш_токен_от_BotFather
SUPPORT_CHAT_ID=6700302188
```

## Сценарии тестирования

### 1. Регистрация пользователя

**Положительный тест:**
1. Отправьте `/start`
2. Ответьте на вопрос верификации (например, "2" для "1+1")
3. Нажмите "Регистрация"
4. Введите имя: "Тест" (корректная длина)
5. Выберите пол: "Парень" или "Девушка"
6. Введите возраст: "25" (валидный возраст 12-100)
7. Выберите цель: "Общение"
8. Выберите регион
9. Нажмите "Загрузить фото" или "Без фото"

**Ожидаемый результат:** Успешная регистрация, сохранение данных

**Негативные тесты:**
- Имя: "А" (меньше 2 символов) → Ошибка: "Имя должно содержать минимум 2 символа"
- Имя: "ОченьДлинноеИмяКотороеПревышаетЛимит" → Ошибка: "Имя слишком длинное"
- Возраст: "abc" → Ошибка: "Пожалуйста, введите корректное число"
- Возраст: "120" → Ошибка: "Возраст должен быть от 12 до 100 лет"

### 2. Регистрация с ошибкой верификации

1. Запустите `/start`
2. Ответьте НЕВЕРНО на вопрос
3. Проверьте сообщение об ошибке

**Ожидаемый результат:** Сообщение "Неверно!" и выход

### 3. Загрузка фото

1. Введите команду `/upload_photo`
2. Нажмите кнопку "Загрузить фото"
3. Отправьте изображение

**Ожидаемый результат:** Сообщение "Фотография загружена!"

### 4. Поиск анкет

1. Нажмите "Знакомиться"
2. Проверьте отображение анкеты
3. Нажмите "❤️ Лайк" или "💔 Дизлайк"

**Ожидаемый результат:** Корректное отображение анкеты, переход к следующей

### 5. Фильтры

1. Введите команду `/filter`
2. Выберите критерий (например, "Пол")
3. Выберите значение ("Парень")
4. Начните знакомиться

**Ожидаемый результат:** Анкеты отфильтрованы по выбранному критерию

**Негативный тест:**
- Выберите неверное значение при фильтре (например, рукописный текст)
**Ожидаемый результат:** Сообщение об ошибке с просьбой выбрать из предложенных

### 6. Просмотр профиля

1. Введите `/my_profile`
2. Отправьте корректное фото

**Ожидаемый результат:** Отображение анкеты с фото

### 7. Сообщение в поддержку

1. Введите `/support`
2. Отправьте сообщение корректной длины (до 1000 символов)

**Ожидаемый результат:** Сообщение "Ваше сообщение отправлено в поддержку!"

**Негативный тест:**
- Отправьте очень длинное сообщение (> 1000 символов)
**Ожидаемый результат:** Сообщение об ошибке о длине

### 8. Удаление профиля

1. Введите `/delete_profile`

**Ожидаемый результат:** Сообщение "Твоя анкета удалена"

### 9. Выход

1. Введите `/exit`

**Ожидаемый результат:** Сообщение "Спасибо за использование бота!"

## Проверка логов

Логи бота выводятся в консоль при запуске. Проверьте наличие:

- `INFO` сообщений - нормальная работа
- `ERROR` сообщений - ошибки (должны присутствовать только при тестировании негативных сценариев)

### Пример лога:

```
2026-02-03 15:30:00 - root - INFO - Запуск старт..
2026-02-03 15:30:05 - root - INFO - Сохранение данных...
2026-02-03 15:30:10 - root - INFO - Запуск знакомства..
```

### Ошибки в логах (нормально для негативных тестов):

```
2026-02-03 15:31:00 - root - ERROR - Validation error in input_name: ValidationError: Имя должно содержать минимум 2 символа
```

## Solving Problems

### Bot не запускается

**Проблема:** Ошибка импорта telegram
**Решение:** Установите python-telegram-bot
```powershell
.\new-env\Scripts\pip.exe install python-telegram-bot==20.8
```

### Ошибка токен

**Проблема:** `Telegram API error`
**Решение:** Проверьте токен в .env файле

### Нет реакции на команды

**Проблема:** Бот не отвечает
**Решение:**
1. Проверьте, что бот запущен
2. Проверьте, что вы написали боту (а не в личку в Telegram)
3. Проверьте, что токен правильный

### Ошибка базы данных

**Проблема:** `JSONDecodeError`
**Решение:** Проверьте JSON файлы, возможно они повреждены. Восстановите из бэкапа (`.bak` файлы)
